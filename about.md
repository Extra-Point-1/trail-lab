# About Trail Lab

Trail Lab is an advanced but lightweight customization tool for Geometry Dash trails.

## Features

Customize trail appearance independently for each game mode:

- **Trail Length** - Adjustable fade time with slider
- **Trail Width** - Fine-grained stroke width control
- **Trail Opacity** - Adjustable transparency
- **Trail Color** - Full RGB color per game mode
- **No Pulse** - Disable pulse effects on trails
- **Independent Profiles** - Separate settings per game mode
- **Presets** - Save and load configurations

## Supported Game Modes

Cube, Ship, Wave, UFO, Ball, Robot, Spider

## Requirements

- Geometry Dash 2.208
- Geode Loader 5.11.2+
- Android (ARM64)
